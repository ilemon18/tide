# Copy, locales and errors

**Load when:** adding UI copy, placeholders/plurals, a locale, native Dock/tray strings, or a backend error
code.
**Code:** `src/i18n/`, `src/lib/ipc.ts`, `src-tauri/src/{i18n,error}.rs`, `src/editor/locale.ts`.

## Source and catalog rules

- `src/i18n/messages/en.ts` is the source of truth (`MessageKey = keyof typeof en`). The other five
  catalogs are complete typed records.
- UI copy goes through `t()` / `tp()`; no hardcoded CJK text in UI string literals. CJK comments are fine.
  `pnpm i18n:scan` catches string literals in code, not translated catalog values.
- Placeholders are named `{name}` and are never translated; word order may differ.
- Plurals use `'singular | plural'` with `tp(key, count)`. `zh-CN`, `zh-TW`, `ja` and `ko` use one form;
  `es` follows English's two-form convention. Add keys with the locale's required form count.
- Locale is live. `applyLocale()` updates `<html lang>`, notifies non-React subscribers, and pushes a
  `localeEffect` into every editor view. DOM-producing CodeMirror extensions must subscribe/unsubscribe
  in `src/editor/locale.ts`; React rerenders alone will not update them.
- A setting shared by every window belongs in `SHARED_KEYS` in `src/store/settings.ts`. Missing it appears
  as “the other window did not update”.

## Backend errors

Rust sends error codes, not translated sentences:

- `AppError::c("code")` for a translatable key.
- `AppError::p("code", params)` for a key plus named placeholder values.
- `AppError::new(raw)` only for external tool output, rendered through `error.message` and never translated.

The frontend renders `error.<code>`; params must match the catalog placeholders. `src-tauri/src/error.rs`
maps IO kinds to `io.notFound` / `io.permissionDenied` / `io.other`, which the i18n checker parses. Every
other `error.<code>` must correspond to a code Rust actually emits, and every emitted code needs all six
catalog entries.

## Add copy or a locale

- **Copy:** add the key to `en.ts` and the other five catalogs with identical placeholders and plural-form
  count, then use `t('key')` or `t('key', { ... })` at the UI boundary.
- **Locale:** add `messages/<locale>.ts`, update `LOCALES` / `LOCALE_LABELS`, and map the tag in
  `src-tauri/src/i18n.rs` for native Dock/tray copy.

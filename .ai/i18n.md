# Copy, locales and errors

## Catalogs

- `src/i18n/messages/en.ts` defines `MessageKey`. All five other catalogs are complete typed records. Add
  every key to all six, preserve named placeholders, then call `t` at the UI boundary. Keep actionable errors,
  consequential behavior and accessible labels; use clear actions and contextual tooltips for optional help.
- No hardcoded CJK UI literals (comments allowed); `i18n:scan` scans code, not catalogs. Named `{name}`
  placeholders stay untranslated and reorderable. `tp` uses singular | plural: one form in zh-CN/zh-TW/ja/ko,
  two in es. A new locale updates messages, `LOCALES`/`LOCALE_LABELS` and Rust i18n tags for Dock/tray.

## Live locale and errors

- `applyLocale` updates `html lang`, non-React subscribers and CodeMirror `localeEffect`. DOM extensions must
  subscribe via `src/editor/locale.ts` and unsubscribe on destroy. Cross-window settings follow `SHARED_KEYS`
  in [settings.md](./settings.md).
- Errors follow [context.md](./context.md): Rust sends codes/params and the frontend resolves `error.<code>`.
  Placeholder names match params; raw external-tool `error.message` is never translated. Rust `error.rs` maps
  IO kinds to `io.notFound`/`io.permissionDenied`/`io.other`; every emitted code needs six catalog entries and
  every other error key must match an emitted code.

## Change map

Change Rust emitters/IO mappings, IPC DTOs and all catalogs together. Existing parity checks protect keys,
placeholders, plurals and error coverage; `i18n:scan` protects CJK literals. Run only requested checks via
[checks.md](./checks.md).

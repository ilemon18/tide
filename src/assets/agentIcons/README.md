# Agent provider icons

These files are the official provider marks used by the Agent settings list:

- `aider.png`: <https://raw.githubusercontent.com/Aider-AI/aider/main/aider/website/assets/icons/favicon-32x32.png>
- `crush.png`: <https://raw.githubusercontent.com/charmbracelet/crush/main/internal/ui/notification/crush-icon-solo.png>
- `droid.svg`: <https://factory.ai/favicon.svg>

The monochrome Claude, Codex, Gemini, Cursor, GitHub Copilot, OpenCode and Qwen paths come from
Simple Icons 16.38.0. Goose and Amp use the monochrome paths from LobeHub static icons 1.104.0:

- <https://unpkg.com/@lobehub/icons-static-svg@1.104.0/icons/goose.svg>
- <https://unpkg.com/@lobehub/icons-static-svg@1.104.0/icons/amp.svg>
